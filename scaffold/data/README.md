# Customer Data

Place customer-provided data files (CSV, Excel, JSON) in this directory.

Then run `/vibe-data-prep` in Copilot Chat to:

1. Analyze and clean the data
2. Generate TypeScript interfaces and C# record types
3. Create a data loading service
4. Produce a data dictionary below
