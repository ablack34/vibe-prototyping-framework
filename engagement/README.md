# Engagement Artifacts

This folder holds **shared, durable engagement artifacts** generated by the VIBE agents. **It IS committed to git** so every team member (TPM, designer, engineer) can see the same engagement state after a `git pull`.

## What Lives Here

After you run `/vibe-kickoff`, an `engagement/{{engagement-kebab}}/` subfolder is created. Agents write the following files to it:

### Preparation (Week 0)

| File | Generated By | Used By |
|------|-------------|---------|
| `PROJECT-CONTEXT.md` | `/vibe-kickoff`, then refined by every later phase | Every VIBE agent — single source of truth |
| `engagement-brief.md` | `@VIBE Preparation` (S42-internal view) | The team |
| `customer-brief.md` | `/vibe-customer-brief` (customer's voice — draft) | `@VIBE Discover`, `@VIBE Disrupt` |

### Discover (Week 1)

| File | Generated By | Used By |
|------|-------------|---------|
| `discovery-summary.md` | `@VIBE Discover` | `@VIBE Disrupt`, `@VIBE Define` (legacy), `@VIBE Deliver` |
| `personas.md` | `/vibe-personas` (required deliverable) | `@VIBE Disrupt`, `@VIBE Define` (legacy) |
| `problem-statement.md` | `/vibe-problem-statement` (required deliverable) | `@VIBE Disrupt`, `@VIBE Define` (legacy) |
| `current-state-journey.md` | `/vibe-current-journey` (required deliverable) | `@VIBE Disrupt`, `@VIBE Define` (legacy) |
| `transcript-analysis.md` | `@VIBE Transcript Analyst` | `@VIBE Discover`, `@VIBE Disrupt` |

## What Does NOT Live Here

- **`state.json`** lives in `.copilot-tracking/vibe/{{engagement-kebab}}/` (gitignored, per-user). Each team member regenerates their own view of phase progress from the committed artifacts.
- **`requirements-summary.md`, `solution-design.md`, `CHECK-IN-NOTES.md`, `PROTOTYPE-LIMITATIONS.md`, `engineering-brief.md` (legacy)** currently live in `templates/` as fill-in-place singletons. They will move to `engagement/{{engagement-kebab}}/` in a future PR alongside the Define/Ideate retirement.
- **Customer source materials** (decks, transcripts, questionnaire exports) live in `sources/` (committed).
- **Blank scaffold templates** live in `templates/` and are **read-only** — agents and facilitators copy from `templates/` into `engagement/{{engagement-kebab}}/` and fill there. `git diff templates/` should always be empty.

## Why This Folder Exists

Without it, the TPM's discovery and ideation work was trapped on their machine — the engineer couldn't read the engineering brief without screen-sharing or zipping files. Committing these artifacts means the engineer just does `git pull` and reads [storyboard.md](storyboard.md) (Disrupt path) or [engineering-brief.md](engineering-brief.md) (legacy Ideate path).
