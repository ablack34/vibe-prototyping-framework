# Engineering Brief

> **Technical half of the VIBE PRD.** Engineer-facing handoff with form factor, mock data, prioritized features, non-goals, and demo script. Pair with [requirements-summary.md](requirements-summary.md) (the business half) for a complete Product Requirements Document.
>
> **Reference template.** The actual engineering brief for an engagement is **auto-generated** by `/vibe-ideate` into `engagement/{{engagement-kebab}}/engineering-brief.md`. This file in `templates/` exists so engineers and the Ideate agent know what a good brief looks like — fields, ordering, and tone.
>
> **You normally do not edit this file directly.** Run `/vibe-ideate` to produce the real brief from the selected concept.

## Acceptance for Handoff to Build

The brief is complete when:

- [ ] Form factor is unambiguous
- [ ] Every must-have feature traces to a prioritized requirement
- [ ] Data sources exist (in `sources/sample-data/` or are noted as TBD with a fallback)
- [ ] Hard constraints are explicit
- [ ] Demo script is end-to-end runnable
- [ ] Non-goals are agreed by the squad
